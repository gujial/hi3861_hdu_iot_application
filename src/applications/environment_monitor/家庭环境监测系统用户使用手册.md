# 家庭环境监测系统用户使用手册

## 1. 手册说明

本手册面向居住者、家人和日常维护人员，说明如何查看家庭环境数据、设置报警阈值、接收手机通知并处理常见问题。系统监测以下三项数据：

- 温度，单位为 °C；
- 相对湿度，单位为 %RH；
- MQ-2 燃气传感器电阻，单位为 kΩ。

系统通过 Hi3861 设备在家中持续采集数据。设备使用 OLED 显示当前读数，发现异常时启动蜂鸣器；数据经华为云 IoTDA 传送到 Web 应用，Web 后端保存历史记录并通过 ntfy 向手机推送报警。

> 本系统用于辅助发现家庭环境异常，不能替代经过认证的燃气报警器、烟雾报警器、消防设施或紧急呼叫设备。MQ-2 显示的是传感器电阻，并非可燃气体 ppm 浓度。

## 2. 使用前准备

请向系统管理员取得以下信息：

1. Web 应用访问地址；
2. Web 访问令牌；
3. ntfy 服务地址和订阅主题；
4. 发生报警后的家庭联系人与处置约定。

设备应安装在通风正常、不易进水、供电稳定的位置。不要遮挡传感器，不要将设备放在火焰、蒸汽、油烟出口或空调出风口正前方。燃气报警功能应由维护人员在 MQ-2 充分预热和标定后开启。

## 3. 日常使用

### 3.1 启动设备

接通设备电源后，等待 OLED 显示温度、湿度和燃气传感器电阻。设备会自动连接 Wi-Fi 和华为云，不需要居住者进行操作。

如果 OLED 长时间没有数据、反复重启或蜂鸣器异常持续鸣响，请联系维护人员。不要自行拆线或修改设备配置。

### 3.2 打开 Web 应用

1. 使用手机或电脑浏览器打开管理员提供的 Web 地址；
2. 在“连接本地监测服务”区域输入访问令牌；
3. 点击“连接”；
4. 页面出现三项读数后，即可开始查看。

访问令牌只保存在当前页面内存中。刷新页面或关闭浏览器后，通常需要重新输入。不要将访问令牌发送给无关人员，也不要在公共电脑上保存令牌。

### 3.3 判断连接状态

页面右上方显示当前连接状态：

| 页面状态 | 含义 | 建议操作 |
|---|---|---|
| 数据更新中 | 后端正在接收近期设备数据 | 正常使用 |
| 等待连接 | 尚未输入令牌或页面正在等待服务 | 输入令牌并稍候 |
| 连接异常 | Web 服务不可访问、令牌错误或接口返回错误 | 检查地址和令牌，必要时联系维护人员 |
| 数据未更新 | 页面显示的是历史读数，设备近期没有新数据 | 查看设备供电和家庭网络，不要把历史值当成当前安全状态 |
| 尚无设备上报 | 系统还没有收到有效数据 | 等待设备上线或联系维护人员检查云连接 |

页面每 5 秒自动刷新一次。关闭网页不会停止后端监测和 ntfy 通知。

## 4. 查看环境数据

### 4.1 当前读数

页面顶部的三张数据卡分别显示温度、相对湿度和燃气传感器电阻。每张卡还会显示当前状态：

- **正常范围**：读数位于启用的上下限之间；
- **超过上限**：读数高于上限；
- **低于下限**：读数低于下限；
- **未启用报警**：该项目只显示数据，不进行阈值报警；
- **历史读数**：数据已经超过有效时间，暂不用于产生新报警。

### 4.2 变化趋势

“变化趋势”区域显示最近 180 次有效采集记录。点击“温度”“相对湿度”或“燃气传感器电阻”可以切换曲线。图表上方显示当前曲线的最高值和最低值，底部显示记录的起止时间。

趋势图适合判断异常是瞬时波动还是持续变化。它不能代替现场检查，也不能证明燃气浓度符合安全标准。

## 5. 设置报警阈值

### 5.1 字段含义

“报警阈值”区域为每项数据提供四个设置：

| 设置 | 含义 |
|---|---|
| 启用开关 | 开启后，设备和 Web 按该项目的上下限判断异常 |
| 下限 | 读数低于该值时进入低值报警状态 |
| 上限 | 读数高于该值时进入高值报警状态 |
| 恢复缓冲 | 读数需要离开报警边界一定距离后才恢复正常，用于减少边界附近反复报警 |

例如温度上限为 35°C、恢复缓冲为 0.5°C：温度高于 35°C 时报警，之后需要降至 34.5°C 或更低才恢复正常。

### 5.2 修改步骤

1. 确认页面显示“数据更新中”，并确认设备在线；
2. 根据需要打开或关闭对应项目；
3. 输入下限、上限和恢复缓冲；
4. 确保下限小于上限，恢复缓冲小于上下限间距的一半；
5. 点击“保存阈值”；
6. 等待页面显示“阈值已下发，设备确认后已保存”；
7. 查看阈值同步状态，确认设备已经返回命令编号或确认信息。

保存时，Web 后端通过华为云向在线设备发送 `SetThresholds` 命令。设备校验设置并写入本地 KV 存储后才返回成功，随后 Web 后端保存同一组规则。普通断电或重启后，设备会继续使用已保存的阈值。

如果设备离线、命令超时或参数非法，本次保存会失败，原有设备阈值和 Web 阈值保持不变。请不要连续点击“保存阈值”，应先阅读页面提示并解决连接问题。

### 5.3 阈值设置原则

- 根据居住者健康情况、季节和房间用途设置温湿度范围；
- 先观察一段时间的正常趋势，再逐步调整，避免上下限过窄造成频繁报警；
- 不要直接复制其他 MQ-2 模块的燃气电阻阈值；
- MQ-2 未完成预热、清洁空气基线测量和受控标定前，应保持燃气报警关闭；
- 修改阈值后应进行一次安全的报警与恢复测试，并通知所有家庭联系人。

## 6. 报警与恢复

### 6.1 现场蜂鸣器

| 蜂鸣模式 | 含义 |
|---|---|
| 单次长声 | 温度或湿度异常 |
| 连续三短声 | 已启用且完成标定的燃气电阻监测出现异常 |

设备在正常状态首次变为异常状态时，会立即把当前异常读数加入 MQTT 上报队列，无需等待普通 30 秒上报周期。持续异常仍按普通周期上报，避免产生过多消息。实际到达 Web 和手机的时间还会受到网络、华为云更新和后端轮询周期影响。

### 6.2 Web 报警记录

“报警记录”显示最近 40 条报警和恢复事件：

- **阈值报警**：指标首次超过上限或低于下限；
- **状态更新**：指标恢复正常或监测被关闭；
- **已推送**：ntfy 已确认接收该通知；
- **待推送**：通知尚未送达，后端会按顺序重试。

持续处于同一种异常状态时，系统不会反复创建相同报警。恢复通知不会越过仍在等待重试的原报警。

### 6.3 手机 ntfy 通知

1. 在手机上安装并打开 ntfy 客户端，或使用管理员提供的 ntfy 网页；
2. 添加管理员提供的服务器地址和主题；
3. 如果主题受保护，按管理员提供的方式完成授权；
4. 允许系统通知，并确认手机没有禁止 ntfy 后台运行；
5. 使用安全方法进行一次测试报警，确认本人和至少一名家人能够收到消息。

同一个 ntfy 主题可由本人和多位家人订阅。通知中包含指标、读数、阈值、时间和事件编号。网络超时可能造成极少量重复通知，可通过事件编号识别同一事件。

## 7. 收到报警后的处理

### 7.1 温度或湿度异常

1. 先联系家中人员确认实际情况；
2. 检查空调、暖气、加湿器、除湿机和门窗状态；
3. 关注老人或行动不便者是否出现不适；
4. 环境恢复后确认页面出现恢复记录；
5. 如果读数明显异常但现场环境正常，请联系维护人员检查传感器位置和阈值。

### 7.2 疑似燃气异常

如果现场闻到燃气气味，或合规燃气报警器同时报警：

1. 不要点火，不要开关灯具、电器或其他可能产生火花的设备；
2. 在确保自身安全的前提下关闭气源并打开门窗；
3. 立即离开危险区域，帮助老人或行动不便者撤离；
4. 到室外安全位置联系燃气公司、物业或当地应急服务；
5. 未经专业人员确认安全，不要返回现场。

只有本系统的 MQ-2 电阻读数异常、现场没有任何危险迹象时，也应先联系现场人员检查通风、油烟、酒精蒸气等可能影响传感器的因素，并核对合规燃气报警器状态。

### 7.3 数据未更新

“数据未更新”表示系统无法确认当前环境是否安全。请依次检查：

1. 开发板是否有电，OLED 是否仍在刷新；
2. 家庭 Wi-Fi 和互联网是否正常；
3. Web 页面中的云连接状态；
4. 问题持续时联系维护人员检查 NTP、MQTT 和华为云设备状态。

断网期间设备仍会继续本地采集、显示和蜂鸣，但远程页面和手机通知可能延迟或缺失。

## 8. 常见问题

| 问题或提示 | 处理方法 |
|---|---|
| “访问令牌无效”或 HTTP 401 | 重新输入管理员提供的正确令牌；令牌变更后刷新页面 |
| “Failed to execute 'json'”或无效响应 | Web 后端可能未运行或代理地址错误，联系维护人员检查服务 |
| `ECONNREFUSED 127.0.0.1:8787` | Web 开发页面无法连接后端，维护人员需要启动 API 服务 |
| 页面一直显示“尚无设备上报” | 检查设备供电、Wi-Fi、华为云设备是否在线以及产品服务 ID |
| 保存阈值超时 | 确认设备在线和 MQTT 已连接，稍后重试；不要假定设备已经采用新阈值 |
| 重启后阈值是否丢失 | 正常断电和重启不会丢失；完整擦除 Flash、恢复出厂或重新烧录并清除 KV 后可能恢复默认值 |
| 燃气读数变化很大 | 先检查预热时间、安装位置和环境干扰；未标定前关闭燃气报警 |
| 报警记录显示“待推送” | 检查 ntfy 服务、主题、授权和手机网络；后端会继续重试 |
| 串口出现异常边沿上报日志但 Web 尚未更新 | 该日志只表示异常读数已入队；继续检查 MQTT 连接、IoTDA 影子时间和 Web 轮询状态 |

## 9. 日常维护建议

- 每周确认设备有电、OLED 正常刷新、Web 数据时间为最新；
- 每月进行一次安全的温湿度测试报警，确认蜂鸣器和手机通知可用；
- 修改家庭 Wi-Fi、云端设备信息或访问令牌后，由维护人员同步更新配置；
- 定期备份 Web 后端的 SQLite 数据库；
- 定期检查 ntfy 订阅、手机通知权限和家庭联系人；
- MQ-2 更换、老化或安装环境变化后重新标定；
- 不在截图、聊天记录或公开文档中泄露访问令牌、Wi-Fi 密码、IAM 密码、MQTT 密码或 DeviceSecret。
